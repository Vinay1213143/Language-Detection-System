# 🌐 Language Detection System using Python & Machine Learning

## 📌 Project Overview
The Language Detection System is a Machine Learning-based application that predicts the language of a given text input. It uses Natural Language Processing (NLP) techniques and a Multinomial Naive Bayes classification algorithm to identify different languages.

## 🎯 Project Objectives
- Detect the language of user-provided text.
- Apply NLP techniques for text processing.
- Understand Machine Learning classification.
- Build a text-based language prediction model.

## 🛠️ Technologies & Libraries
- Python
- NumPy
- Pandas
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

## ⚙️ Project Workflow
1. Load and explore the language dataset using Pandas.
2. Convert text into numerical features using CountVectorizer.
3. Split the dataset into training and testing sets.
4. Train the model using Multinomial Naive Bayes.
5. Evaluate the trained model.
6. Predict the language of new text input.

## 🧠 Machine Learning Algorithm
**Multinomial Naive Bayes**

Used for text classification based on word-frequency features.
